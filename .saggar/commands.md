# Commands

- Dev server: `npm start` #monitor #browser
- Build: `npm run build` #quick
- Serve build: `npm run serve` #monitor #browser
- MCP server: `npm run mcp` #monitor
- Typecheck: `npm run typecheck` #quick
- Lint: `npm run lint` #quick
- Format check: `npm run format:check` #quick
- Clear cache: `npm run clear` #quick

# Docusaurus plugins

A family of small, focused plugins for Docusaurus v3 — documented and **dogfooded** on this site. Every plugin you read about here is installed and running right now on the site you're looking at.

## Plugins

| Plugin                                          | What it does                                                                          |
| ----------------------------------------------- | ------------------------------------------------------------------------------------- |
| [Banner](/docs/banner/overview)                 | Adds a dismissible announcement above the navbar.                                     |
| [Cookie consent](/docs/cookie-consent/overview) | Collects and stores consent choices before optional scripts load.                     |
| [Embeds](/docs/embeds/overview)                 | Adds rich MDX cards for links, GitHub repositories, npm packages, and YouTube videos. |
| [Glossary](/docs/glossary/overview)             | Generates a glossary and links defined terms across your docs.                        |
| [Marginalia](/docs/marginalia/overview)         | Pairs inline anchors with editorial sidenotes in the page margin.                     |
| [MCP](/docs/mcp/overview)                       | Exposes docs and OpenAPI specifications to agents through MCP.                        |
| [New post toast](/docs/new-post-toast/overview) | Shows returning readers the blog posts published since their last visit.              |
| [Open with LLM](/docs/open-with-llm/overview)   | Lets readers copy, download, or open a docs page as Markdown in an LLM.               |
| [omg](/docs/omg/overview)                       | Compiles OpenAPI Markdown Grammar into OpenAPI 3.1 during the Docusaurus build.       |
| [Starter](/docs/starter/overview)               | Provides a typed template for building a Docusaurus plugin.                           |
| [Statuspage](/docs/statuspage/overview)         | Displays current incidents from a public Statuspage.io instance.                      |

## Speccy

[Speccy](https://github.com/mcclowes/speccy/tree/main/packages/docusaurus-plugin) adds an OpenAPI reference route or embeddable reference to a Docusaurus site. It lives in its own repository, where you'll find its installation and configuration docs. The package is available as [`docusaurus-plugin-speccy`](https://www.npmjs.com/package/docusaurus-plugin-speccy).

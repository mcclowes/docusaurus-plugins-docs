This site documents a family of Docusaurus v3 plugins — and it uses every single one of them so each page is a live demo.

<!--truncate-->

The plugins:

- Banner — the thing at the top of this page
- Cookie consent — the consent toast
- Glossary — visit `/glossary` and note the auto-linked terms in these docs
- New post toast — returning visitors get a toast when new posts go out
- Starter — a template for building your own plugin
- Statuspage — a discreet banner on outages

Each plugin is a standalone npm package. This site just installs them.
